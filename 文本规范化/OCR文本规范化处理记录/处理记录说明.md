# OCR 文本规范化处理记录

本目录保留 OCR 文本规范化脚本。完整处理记录和执行统计不随公开仓库提供。

## 用法

先预览处理效果：

```bash
python normalize_ocr_texts_safe.py --root "..\..\OCR结果"
```

确认后原地执行，并在同级目录生成备份：

```bash
python normalize_ocr_texts_safe.py --root "..\..\OCR结果" --apply
```

## 处理原则

- 删除 OCR 元信息、分页标记、网页导航、孤立页码和多余空白
- 保留正文、编号、参数、技术术语和表格型内容
- 不进行语义改写，不补写或删改技术结论
- 正式覆盖前先备份原文件
